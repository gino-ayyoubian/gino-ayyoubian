# 05 Roadmap

- **Phase 0 (weeks 1-2):** create orgs and `.github` repos; enable secret scanning, push protection, Dependabot; rotate exposed secrets.
- **Phase 1 (month 1):** transfer and rename repos; merge duplicate Telegram repos into `lib-` and `svc-`; merge/archive duplicate digital-assets repo; roll out reusable workflows and rulesets.
- **Phase 2 (months 2-3):** containerize; GHCR or internal registry; OpenTofu baseline; OIDC to cloud.
- **Phase 3 (months 3-6):** Kubernetes + GitOps; ephemeral self-hosted runners; audit-log streaming; knowledge-graph portal; AI-assisted review under least-privilege tokens.
- **Phase 4:** multi-cloud orchestration; SOC 2 / ISO 27001 mapping and ongoing audits.
