# Security policy

## Supported content

Security reports are accepted for the current default branch of this
documentation and workflow-example repository. No guarantee is made for
unreleased changes or older revisions.

## Reporting a vulnerability

Please do not publish vulnerability details in an issue or pull request. Use
GitHub's private vulnerability reporting feature for this repository when it is
available. If it is unavailable, contact
[G.ayyoubian@kkm-intl.org](mailto:G.ayyoubian@kkm-intl.org) with a concise
description and a way to reproduce the issue.

The maintainer will acknowledge reports as soon as practicable. Please allow
time for investigation and coordinated remediation before public disclosure.
